================================

Files to upload to the ROOT of the website (same folder level as index.html):

1. robots.txt
2. sitemap.xml

After uploading, check these URLs in your browser:
https://hisaabkitab.co/robots.txt
https://hisaabkitab.co/sitemap.xml

Then:
- Open Google Search Console: https://search.google.com/search-console
- Add/verify the property https://hisaabkitab.co/
- Open Indexing > Sitemaps
- Submit: sitemap.xml
- Inspect each important URL and request indexing if needed.

IMPORTANT:
- This sitemap contains the nine pages currently linked/verified on HisaabKitab.
- When you add a new public calculator or useful content page, add its full canonical URL
  to sitemap.xml and upload the updated file.

- Do not add an ads.txt file until an ad network gives you the exact publisher record.
- These files improve crawl discovery; they do not guarantee rankings or AdSense approval.
