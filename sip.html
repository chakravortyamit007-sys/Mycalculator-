How SIP returns are calculated

Future value = P × [((1+r)n − 1) ÷ r] × (1+r), with P as the monthly amount, r as the monthly return and n as the number of months. Mutual fund returns are not guaranteed; actual returns vary with the market.

Frequently asked questions

Is the return guaranteed?

No. The expected return is an assumption, not a promise.

What is a good SIP period?

Longer periods (7+ years) usually smooth out market ups and downs.
